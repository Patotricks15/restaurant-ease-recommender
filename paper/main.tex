\begin{abstract}
We apply EASE\textsuperscript{R} (Embarrassingly Shallow Autoencoder for
Sparse Recommendation), a closed-form, ridge-regularised item-item linear
model, to the Restaurant Consumer Ratings dataset. Because the dataset
carries no event timestamp, evaluation uses a user-aware random holdout
instead of a temporal split. The system includes a declarative feature
specification, leakage tests, a popularity baseline, and reproducible
Floci/AWS infrastructure.
\end{abstract}
